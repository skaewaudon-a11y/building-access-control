เริ่มต้นใช้งานระบบ
1
ตั้งค่าจุดทางเข้า
ไปที่เมนู จุดทางเข้า แล้วเพิ่มจุดทางเข้าที่ต้องการควบคุม เช่น "Main Entrance Phase 1" พร้อมระบุ Zone และ Site ระบบจะซิงค์ไปยัง Guard Terminal โดยอัตโนมัติ
2
นำเข้าข้อมูลพนักงาน
ใช้เมนู เพิ่มข้อมูลพนักงาน (Import) เพื่ออัปโหลดไฟล์ Excel รองรับ .xlsx .xls .csv ระบบจะตรวจจับ Column อัตโนมัติ และแสดงตัวอย่างก่อน Import
3
สร้างบัญชี Guard
ไปที่เมนู Guard Users แล้วสร้างบัญชีสำหรับเจ้าหน้าที่รักษาความปลอดภัย ระบุ Email, Password, จุดทางเข้าที่รับผิดชอบ Guard จะ Login ผ่านหน้า Guard Terminal แยกต่างหาก
4
เริ่มสแกนที่ Guard Terminal
Guard เปิดไฟล์ guard.html บนอุปกรณ์ที่จุดทางเข้า Login แล้วเลือกจุดทางเข้า จากนั้นสแกน Badge หรือพิมพ์ Emp ID — ระบบตอบสนองทันทีจาก Memory Cache
การจัดการสิทธิ์
A
สิทธิ์ Admin Admin
ใช้เมนู สิทธิ์ Admin เพื่อเพิ่มผู้ดูแลระบบคนใหม่ Admin สามารถเข้าถึง Portal นี้ได้เต็มรูปแบบ ควรมอบสิทธิ์เฉพาะบุคคลที่ได้รับอนุญาตเท่านั้น
G
สิทธิ์ Guard Guard
Guard สามารถ Login ได้เฉพาะ Guard Terminal (guard.html) เท่านั้น ไม่มีสิทธิ์เข้า Admin Portal และไม่สามารถแก้ไขข้อมูลระบบได้
Log และรายงาน
1
กรองตามวันที่
ในหน้า Log ทั้งหมด ใช้ Quick Date Buttons (วันนี้ / 7 วัน / เดือนนี้) หรือกรอกช่วงวันที่เองเพื่อดูข้อมูลย้อนหลัง
2
Export รายงาน
กด PDF เพื่อพรีวิวและพิมพ์รายงาน A4 Landscape หรือกด CSV เพื่อดาวน์โหลดข้อมูลไปวิเคราะห์ต่อใน Excel — ข้อมูลที่ Export จะตรงกับ Filter ที่เลือกอยู่
คำถามที่พบบ่อย
Guard Login ไม่ได้ ทำอย่างไร?▾
ตรวจสอบว่า Guard ใช้ไฟล์ guard.html ไม่ใช่หน้า Admin Portal · ตรวจสอบสถานะ Account ในเมนู Guard Users ว่าเป็น Active · ตรวจสอบ Email และ Password ให้ถูกต้อง
สแกน Badge แล้วขึ้น "ไม่พบข้อมูล" ทั้งที่เป็นพนักงาน?▾
Badge ID ในระบบอาจไม่ตรงกับที่สแกน · ตรวจสอบในหน้า พนักงาน ว่า Badge ID บันทึกถูกต้อง · ข้อมูลพนักงานอาจยังไม่ถูก Import เข้าระบบ
Import พนักงานแล้วข้อมูลหาย หรือไม่ครบ?▾
ตรวจสอบว่าไฟล์ Excel มีคอลัมน์ที่ถูกต้อง เช่น "Emp - ID", "Badge-ID", "Name and Surname (EN)" · ดูผลการ Map Column ในหน้าต่าง Import ก่อนกด Confirm · ลอง Export CSV ดูเพื่อยืนยันข้อมูลในระบบ
จะเพิ่ม Admin คนใหม่ได้อย่างไร?▾
ไปที่เมนู สิทธิ์ Admin แล้วกรอก Email, ชื่อ, Password เริ่มต้น และระดับสิทธิ์ กด "มอบสิทธิ์ Admin" — Admin ใหม่สามารถ Login เข้า Portal นี้ได้ทันที
สถานะ "ปฏิเสธ" ในรายงานหมายความว่าอะไร?▾
Denied หมายความว่า Badge/Emp ID ที่สแกนไม่พบในฐานข้อมูลพนักงาน · Guard ยังคงบันทึก ID ที่สแกนไว้ใน Log เพื่อการตรวจสอบย้อนหลัง
